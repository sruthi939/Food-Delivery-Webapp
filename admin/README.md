# GoldFork Admin Dashboard Application

GoldFork Admin Web Application for managing food delivery operations, menu items, customer orders, categories, users, and customer reviews.

## Features
- **Dashboard Overview**: Key performance indicators (Revenue, Active Orders, Dishes, Users).
- **Food Menu Management**: Add, view, edit, and delete food items with image uploads and Veg/Non-Veg badges.
- **Order Processing**: Real-time status update pipeline (Food Processing → Out for Delivery → Delivered → Cancelled).
- **User Accounts**: Customer and staff administration.
- **Taxonomy & Categories**: Category management with dish counters.
- **Customer Reviews**: Customer ratings and review management.
- **Settings & Configurations**: Restaurant profile, standard delivery fees, contact info.

## Getting Started
```bash
npm install
npm run dev
```
Running on `http://localhost:5174`.
Backend server running on `http://localhost:4000`.
